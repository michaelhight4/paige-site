# Player RUN + BIKE overworld sprites (Cal; Mira in ../../mira/run_bike/)

Generated by `tools/gen_run_bike.py <char>` (Pillow + numpy). It derives from `humans/<char>/overworld/<char>_chibi/*_stand.png`, or falls back to the pilot walk.

- Validate with `tools/validate.py <char>`.
- Update the manifest with `tools/write_manifest.py` (read-merge-write of the `"run_bike"` key only).

## Layout
- `frames/` holds the 64x96 1x frames; `frames_2x/` and `frames_3x/` hold exact nearest-neighbour scales.
  - Run: `<char>_chibi_{down,left,right,up}_run0..5`.
  - Bike: `<char>_chibi_{down,left,right,up}_bike_stand`, `bike0..3`.
- `sheets/<char>_chibi_{run,bike}_sheet(.png,_2x,_3x)`:
  - Rows are down/left/right/up (same as the walk sheet).
  - Run has 6 columns; bike has 5 (stand + 4).
- `gifs/`:
  - Per-direction and `_all` previews at 2x/3x (run 40 ms, bike 60 ms).
  - `<char>_chibi_compare_walk_run_bike_2x.gif` puts walk | run | bike side by side, time-synced to their speeds, with ground ticks scrolling at each speed.
- `parts/<char>_chibi_<dir>_seated_upper.png` is a reusable seated torso for future mounts and train seats.
- Timing, anchors and future-mount notes are in `MOVEMENT_NOTES.md`.
