# Kilumen: Start of a Journey: World Art

Style: bright, painterly 2D fantasy-adventure with warm light. Violet "dominance crystal" glow is the recurring accent.
All art is original and contains no creatures. Each piece was generated at about 1280px and upscaled 2x with PIL LANCZOS (16:9 = 2560x1440).

## Zone names (13 zones, following the design doc's 4 towns / 3 cities / 6 biomes)
The design doc gives zone counts but no names, so these are PROPOSED names. Gary can rename them.
- Towns: Brookhollow (starter river town, home of the player and Ron), Fernwick, Saltmere, Cindervale
- Cities: Revival Heights (Revival Tech HQ), Lanternport (port city), Aurelith (arena city of the Battle Masters)
- Biomes: Sunmeadow Fields (meadow), Thornwood (forest), Greystone Caverns (mountain/cave), Mirefen (swamp), Tidewater Coast (coast/sea), Frostspire (snow peaks)
