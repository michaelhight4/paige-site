# Kilumen interiors (new set)

Generated by `python3 tools/interiors_new.py all` (run from `art/world/overworld/`). Everything lives in `interiors_new/`; nothing in `maps/`, `tileset.json`, `run.py` or the existing `tools/*.py` was touched.

Rules: 64 px native tiles, true pixel art, palette.hex snap with 4x4 Bayer dithering, binary alpha + the one shared shadow rgba(26,18,38,96), nearest-neighbour 1x/2x/3x. Floors tile seamlessly with 2-3 variants (`seam_report.json` is empty = no seams). Furniture sits on transparent decoration tiles.

## Master halls and puzzles

Fernwick's hall already exists (`maps/fernwick_hall_int.json`) and was skipped. Each new hall carries `puzzle` with rules text, element lists, the start, the goal, and `puzzle.verified` from `gen/ix_puzzles.py` (BFS over player position, boulders/stones, switch bits, collapsed crust and mirror states, plus a reverse BFS: `softlock_states` = states from which the goal can no longer be reached without a reset/exit).

| hall | mechanic | states explored | soft-locks | shortest solution |
|---|---|---|---|---|
| hall_aurelith | partial gauntlet: beam wing + boulder wing latch two seals; hold plates open the grand gates | 319588 | 0 | `U5 L5 D2 L U*2 D L Amir1 U2 R*5 D R8 R* U R D*2 R D L*6 U3 L2 U3` |
| hall_cindervale | lava trunk with 3 spill branches; cool-stone dams fill basins; bellows reset | 52738 | 0 | `U3 R4 D R3 U*2 D2 AW1 L2 U L3 D L3 U*2 R U5` |
| hall_lanternport | 5 rotatable mirrors: one lamp beam must light the dock plate and end on the lock receiver; crate blocks beams | 184627 | 0 | `U2 L Amir4 R3 Amir5 U2 R*2 U R Amir3 U L2 Amir2 L4 Amir1 R U3` |
| hall_revival_heights | power cubes onto rail gaps + relay crystal; laser gates with an order trap | 596223 | 0 | `U2 U* R2 R*4 D R U*3 D L6 L*5 D L2 U2 Ac1 D2 R2 U3 R4 U3` |
| hall_saltmere | cracked salt crust (one-step tiles) + 3 latch plates -> seal crystal -> twin gates | 2284029 | 0 | `U3 L U R U R2 U L3 U R U3` |

Solution legend: U/D/L/R steps, a `*` marks a step that pushes, `n` repeats, `A<id>` = interact (rotate mirror, touch crystal, pump bellows).

Engine notes the game code must match (see `gen/ix_puzzles.py`):
* **no_push**: `puzzle.no_push` is a list of cells that boulders/stones/crates can never be pushed onto (door sills, gate cells, bellows fronts). It exists to stop crates being shoved through a gate into an unreachable pocket.
* **Lava spill model** (Cindervale): `lava.trunk` is the ordered channel from the source; it is hot up to the first cool stone sitting in it. `lava.spill` lists [junction, first branch cell]; a branch only fills when the trunk is dammed just below its junction, and branch flow never re-enters the trunk. A basin plate is on while lava reaches it. The player can never end a move on hot lava; cool stones can be pushed onto hot cells (that is how you dam). There is no step timing: flow is instant.
* **Seals and zones** (Aurelith): a seal latches for good once its source channel is on; wing zones reset on exit unless their seal is latched.
* Hold plates / beam plates count only while occupied / lit; latch plates stay on until a reset crystal.

`tools/run.py`'s solver only models boulders + switches, so it cannot check these halls; use `gen/ix_puzzles.py` (`python3 tools/interiors_new.py check`).
